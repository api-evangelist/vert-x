Eclipse Vert.x 5.1.1 has been released as a patch update to the 5.1 series for the reactive JVM toolkit. This maintenance release addresses bug fixes and stability improvements following the 5.1 feature release. Developers can upgrade via Maven Central or the Vert.x website.
